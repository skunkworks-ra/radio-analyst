# Reduction Ledger (Automatic via `stage_log.jsonl`)

Every `ms_modify` write tool (and `ms_import_asdm`) automatically records each
generated script or `execute=True` action to `<workdir>/stage_log.jsonl` with
its tool name, literal parameters, `script_path`, output paths, and timestamp.

`ms_reduction_log(action='list' | 'render', workdir=...)` and `ms_report` read
`<workdir>/stage_log.jsonl` directly:

- Scripted steps (`execute=False`) are included only once their script has run
  to completion (`<script>.rc == 0`, or expected outputs verified on disk).
- Superseded solves (the same `(tool, ms_path, output_key)` re-generated on a
  retry or re-solve) automatically collapse to the final effective run in order.
- Diagnostic read-only tools are never entries in the replay recipe.

**Stage agents and stage commands do NOT call `ms_reduction_log(action='append')`.**
There is zero manual ledger-append overhead during `precal`, `calibrate`,
`polcal`, `postcal`, `image`, or `selfcal`.

## When to call `ms_reduction_log` directly

Use `ms_reduction_log` only in interactive or reporting sessions:

- `ms_reduction_log(action='list', workdir=<workdir>)` -- inspect the ordered
  effective steps recorded so far.
- `ms_reduction_log(action='render', workdir=<workdir>)` -- write executable
  `<workdir>/reduction_replay.py` and return `recipe` in the tool response
  (`ms_report` renders `<workdir>/report.html`).
- `ms_reduction_log(action='append', workdir=<workdir>, tool='manual',
  params={...}, script_path=<script>, rationale=<one line>)` -- record a custom
  off-tool Python/CASA script (`tool='manual'`) or attach a manual annotation
  that was not generated by an MCP write tool.
